Abstract Sets and Mappings

Lawvere’s categorical approach to sets — axioms and exercises from Chapter 1 of Lawvere–Rosebrugh

Author
Affiliation

Jan Reimann

Penn State — Math 558

These notes follow Chapter 1 of Lawvere–Rosebrugh, Sets for Mathematics. Numbers such as “Definition 1.14” or “Exercise 1.15” refer to the book. In the exercises taken from §§1.5–1.8 (1.15–1.28), argue only from the axioms and definitions stated here, plus ordinary logic; do not appeal to what you know about sets from \(\mathsf{ZFC}\). In Exercise 1.30 you work in ordinary mathematics, to see how much of the structure of abstract sets is shared by other familiar categories. When an exercise is a statement, prove the statement.

Sets as a category

In \(\mathsf{ZFC}\) the primitive notion is membership: a set is determined by its elements, and everything else (pairs, functions, …) is coded by membership. In Lawvere’s approach the primitive notions are sets and mappings between them, together with composition of mappings. An abstract set has no internal structure beyond the fact that its elements can be told apart; everything we want to say about a set must be expressed through the mappings into and out of it. Even “element” becomes a derived notion: an element of \(A\) is a particular kind of mapping into \(A\).

Categories

Definition 14.1 (Category (L–R, Definition 1.13)) A category \(\mathcal{C}\) has the following data:

  • Objects, denoted \(A, B, C, \dots\)
  • Arrows, denoted \(f, g, h, \dots\) (also called morphisms or maps).
  • To each arrow \(f\) is assigned an object \(\operatorname{dom}(f)\), its domain, and an object \(\operatorname{cod}(f)\), its codomain. If \(\operatorname{dom}(f) = A\) and \(\operatorname{cod}(f) = B\) we write \(f \colon A \to B\) or \(A \xrightarrow{\;f\;} B\).
  • Composition: to each pair \(f \colon A \to B\) and \(g \colon B \to C\) is assigned an arrow \(gf \colon A \to C\), called “the composite \(g\) following \(f\)” (also written \(g \circ f\)).
  • Identities: to each object \(A\) is assigned an arrow \(1_{A} \colon A \to A\), called “the identity on \(A\)”.

These data satisfy the axioms

  • Associativity: if \(A \xrightarrow{\;f\;} B \xrightarrow{\;g\;} C \xrightarrow{\;h\;} D\), then \(h(gf) = (hg)f\);
  • Identity: if \(f \colon A \to B\), then \(f = f\,1_{A}\) and \(f = 1_{B}\,f\).

Note that \(gf\) is only defined when the codomain of \(f\) is exactly the domain of \(g\). A diagram of objects and arrows is commutative if any two paths of arrows with the same start and end have equal composites; for example, the triangle formed by \(f \colon A \to B\), \(g \colon B \to C\) and \(m \colon A \to C\) commutes precisely when \(m = gf\).

Definition 14.2 (Isomorphism) Objects \(A\) and \(B\) of a category are isomorphic, written \(A \cong B\), if there are arrows \(f \colon A \to B\) and \(g \colon B \to A\) with \(gf = 1_{A}\) and \(fg = 1_{B}\). Such an \(f\) is an isomorphism.

Definition 14.3 (Terminal and initial objects) An object \(T\) of a category \(\mathcal{C}\) is terminal if for every object \(A\) of \(\mathcal{C}\) there is exactly one arrow \(A \to T\). An object \(I\) is initial if for every object \(A\) there is exactly one arrow \(I \to A\).

Remark 14.1. The book introduces “terminal” and “initial” only for the category of sets (see the axioms below), but the definitions make sense in any category, and that is how they are used in Exercise 14.6.

The axioms of Chapter 1

We write \(\mathcal{S}\) for the category of abstract sets and (arbitrary) mappings.

NoteAxiom: \(\mathcal{S}\) is a category

Abstract sets and mappings form a category, whose objects are called sets and whose arrows are called mappings.

NoteAxiom: Terminal set

There is a set \(\mathbf{1}\) such that for any set \(A\) there is exactly one mapping \(A \to \mathbf{1}\).

The book gives this unique mapping the same name \(A\) as its domain; to avoid confusion we write it \(!_{A} \colon A \to \mathbf{1}\). In a given discussion \(\mathbf{1}\) denotes a chosen terminal set (by Exercise 14.5 (b) the choice makes no difference).

Definition 14.4 (Element (L–R, Definition 1.3)) An element of a set \(A\) is any mapping whose codomain is \(A\) and whose domain is \(\mathbf{1}\), i.e. any \(a \colon \mathbf{1}\to A\).

Thus element is a special case of mapping, and evaluation is a special case of composition: if \(f \colon A \to B\) and \(a \colon \mathbf{1}\to A\), then \(fa \colon \mathbf{1}\to B\) is an element of \(B\), and we define the value of \(f\) at \(a\) by \(f(a) := fa\). Associativity then gives \((gf)(a) = g(f(a))\).

Definition 14.5 (Generalized element (L–R, §1.6)) A generalized element of \(A\) (or variable element of \(A\) varying over \(T\)) is an arbitrary mapping \(x \colon T \to A\) with codomain \(A\); its domain \(T\) need not be \(\mathbf{1}\).

Definition 14.6 (Separator (L–R, Definition 1.14)) An object \(S\) in a category \(\mathcal{C}\) is a separator if and only if whenever \(f_1, f_2 \colon X \to Y\) are arrows of \(\mathcal{C}\) with the same domain and the same codomain, then \[ \bigl(\forall x\, [\, x \colon S \to X \;\Rightarrow\; f_1 x = f_2 x \,]\bigr) \;\Longrightarrow\; f_1 = f_2 . \]

NoteAxiom: The terminal object \(\mathbf{1}\) separates mappings in \(\mathcal{S}\)

A one-element set \(\mathbf{1}\) is a separator in \(\mathcal{S}\); that is, if \(f_1, f_2 \colon X \to Y\), then \[ \bigl(\forall x\, [\, x \colon \mathbf{1}\to X \;\Rightarrow\; f_1 x = f_2 x \,]\bigr) \;\Longrightarrow\; f_1 = f_2 . \]

In words: two mappings with the same domain and codomain that have the same value at every element are equal. Contrapositively, if \(f_1 \neq f_2\) there is an element \(x\) of \(X\) with \(f_1(x) \neq f_2(x)\).

NoteAxiom: Initial set

There is a set \(\mathbf{0}\) such that for any set \(A\) there is exactly one mapping \(\mathbf{0}\to A\).

NoteAxiom: Nondegeneracy of \(\mathcal{S}\)

\[ \mathbf{0}\not\cong \mathbf{1}. \]

Definition 14.7 (Coseparator (L–R, Definition 1.19)) An object \(V\) of a category \(\mathcal{C}\) is a coseparator if for any \(A\) and any parallel pair \(a_0, a_1 \colon T \to A\) (of generalized elements of \(A\)), \[ \bigl(\forall \varphi\, [\, \varphi \colon A \to V \;\Rightarrow\; \varphi a_0 = \varphi a_1 \,]\bigr) \;\Longrightarrow\; a_0 = a_1 . \] Equivalently: if \(a_0 \neq a_1\), then there is some \(\varphi \colon A \to V\) with \(\varphi a_0 \neq \varphi a_1\). We say that \(V\) can discriminate elements if this condition holds for \(T = \mathbf{1}\).

A mapping \(\varphi \colon A \to V\) is thought of as a (\(V\)-valued) property of the elements of \(A\), so a coseparator is an object of values with enough properties to tell elements apart.

Remark 14.2 (The set \(\mathbf{2}\) (L–R, §1.7)). The book provisionally assumes a set \(\mathbf{2}\) with exactly two elements \(0, 1 \colon \mathbf{1}\to \mathbf{2}\) (made precise by the axioms of Chapter 2) and claims (Claim 1.21) that \(\mathbf{2}\) is a coseparator in \(\mathcal{S}\). None of the exercises below depend on this.

Exercises

Two consequences of the axioms Terminal set and Initial set are used again and again below:

TipA recurring observation

The only mapping \(\mathbf{1}\to \mathbf{1}\) is \(1_{\mathbf{1}}\), and the only mapping \(\mathbf{0}\to \mathbf{0}\) is \(1_{\mathbf{0}}\). More generally, any two arrows into a terminal object with the same domain are equal, and any two arrows out of an initial object with the same codomain are equal.

Separators

Exercise 14.1 (L–R 1.15) In the category of abstract sets \(\mathcal{S}\), any set \(A\) with at least one element \(x_0 \colon \mathbf{1}\to A\) is also a separator.

TipSolution

Let \(f_1, f_2 \colon X \to Y\) and suppose that \(f_1 a = f_2 a\) for every \(a \colon A \to X\). We must show \(f_1 = f_2\). Since \(\mathbf{1}\) is a separator (axiom), it suffices to show \(f_1 x = f_2 x\) for every element \(x \colon \mathbf{1}\to X\).

So fix \(x \colon \mathbf{1}\to X\) and consider the generalized element \[ a := x\,!_{A} \colon A \xrightarrow{\;!_{A}\;} \mathbf{1}\xrightarrow{\;x\;} X , \] the constant map with value \(x\). By hypothesis \(f_1 a = f_2 a\), i.e. \(f_1 (x\,!_{A}) = f_2 (x\,!_{A})\). Composing on the right with the given element \(x_0 \colon \mathbf{1}\to A\) and using associativity, \[ f_1\, x\, (!_{A}\, x_0) \;=\; f_2\, x\, (!_{A}\, x_0). \] Now \(!_{A} x_0 \colon \mathbf{1}\to \mathbf{1}\), and the only mapping \(\mathbf{1}\to \mathbf{1}\) is \(1_{\mathbf{1}}\). Hence \(!_{A} x_0 = 1_{\mathbf{1}}\), and by the identity law \(f_1 x = f_2 x\). As \(x\) was arbitrary, \(f_1 = f_2\).

NoteRemarks

The key idea is to turn an element \(x\) of \(X\) into a generalized element \(A \to X\) by making it constant, and then to recover \(x\) by evaluating at the element \(x_0\) of \(A\). Without \(x_0\) we could not cancel \(!_{A}\), and Exercise 14.2 shows that the hypothesis cannot be dropped.

Exercise 14.2 (L–R 1.16) In the category of abstract sets \(\mathcal{S}\) the initial set \(\mathbf{0}\) is not a separator. (Assume that two sets \(A\) and \(B\) exist with at least two maps \(A \to B\).)

TipSolution

By assumption there are \(f_1, f_2 \colon A \to B\) with \(f_1 \neq f_2\). For \(\mathbf{0}\) to be a separator we would need: if \(f_1 x = f_2 x\) for every \(x \colon \mathbf{0}\to A\), then \(f_1 = f_2\). But for any \(x \colon \mathbf{0}\to A\), both \(f_1 x\) and \(f_2 x\) are mappings \(\mathbf{0}\to B\), and by the axiom Initial set there is exactly one such mapping. Hence \(f_1 x = f_2 x\) for all \(x \colon \mathbf{0}\to A\), while \(f_1 \neq f_2\). So \(\mathbf{0}\) is not a separator.

NoteRemarks

Why is the extra assumption needed? The axioms of Chapter 1 alone do not guarantee two distinct parallel mappings. Consider the category with two objects \(\mathbf{0}, \mathbf{1}\) and only three arrows: \(1_{\mathbf{0}}\), \(1_{\mathbf{1}}\), and one arrow \(u \colon \mathbf{0}\to \mathbf{1}\) (composition is forced). In it \(\mathbf{1}\) is terminal, \(\mathbf{0}\) is initial, every hom-set has at most one element (so every object, including \(\mathbf{0}\), is a separator, and in particular \(\mathbf{1}\) separates), and \(\mathbf{0}\not\cong \mathbf{1}\) because there is no arrow \(\mathbf{1}\to \mathbf{0}\). So all the axioms of Chapter 1 hold, yet \(\mathbf{0}\) is a separator. This is a first example of a model of a fragment of the categorical axioms, much like the small models of fragments of \(\mathsf{ZFC}\) we studied earlier.

Once the set \(\mathbf{2}\) with elements \(0 \neq 1 \colon \mathbf{1}\to \mathbf{2}\) is available (Chapter 2), one can take \(A = \mathbf{1}\), \(B = \mathbf{2}\).

Compare with Exercise 14.1: \(\mathbf{0}\) fails precisely because it has no elements (Exercise 14.3).

The empty set

Exercise 14.3 (L–R 1.18) How many mappings are there from \(\mathbf{0}\) to \(\mathbf{1}\)? From \(\mathbf{0}\) to \(\mathbf{0}\)? From \(\mathbf{1}\) to \(\mathbf{0}\)? (And so how many elements does \(\mathbf{0}\) have?)

Hint: To answer the third question requires more axioms than do the other two.

TipSolution

From \(\mathbf{0}\) to \(\mathbf{1}\): exactly one. This follows from Initial set (with \(A = \mathbf{1}\)), and equally from Terminal set (with \(A = \mathbf{0}\)). Call it \(u \colon \mathbf{0}\to \mathbf{1}\).

From \(\mathbf{0}\) to \(\mathbf{0}\): exactly one, by Initial set with \(A = \mathbf{0}\). Since \(1_{\mathbf{0}}\) is such a mapping, it is \(1_{\mathbf{0}}\).

From \(\mathbf{1}\) to \(\mathbf{0}\): none. Suppose, for a contradiction, that \(x \colon \mathbf{1}\to \mathbf{0}\). Then

  • \(u x \colon \mathbf{1}\to \mathbf{1}\), so \(u x = 1_{\mathbf{1}}\) (Terminal set);
  • \(x u \colon \mathbf{0}\to \mathbf{0}\), so \(x u = 1_{\mathbf{0}}\) (Initial set).

Thus \(x\) and \(u\) are mutually inverse and \(\mathbf{0}\cong \mathbf{1}\), contradicting Nondegeneracy. Hence there is no mapping \(\mathbf{1}\to \mathbf{0}\).

Since elements of \(\mathbf{0}\) are by definition mappings \(\mathbf{1}\to \mathbf{0}\), \(\mathbf{0}\) has no elements: it is an empty set, which justifies the name.

NoteRemarks
  • The first two answers use one axiom each; the third uses Terminal set, Initial set, and Nondegeneracy.
  • The argument shows that, given the other axioms, Nondegeneracy is equivalent to the apparently stronger statement “there is no mapping \(\mathbf{1}\to \mathbf{0}\)”. The converse is immediate: an isomorphism \(\mathbf{0}\cong \mathbf{1}\) includes a mapping \(\mathbf{1}\to \mathbf{0}\).
  • Extension. If there is any mapping \(h \colon A \to \mathbf{0}\), then \(A \cong \mathbf{0}\). With \(e \colon \mathbf{0}\to A\) the unique map, \(he = 1_{\mathbf{0}}\) by initiality. For \(eh = 1_{A}\) one needs one more axiom: \(A\) has no elements (an element \(a\) would give an element \(ha\) of \(\mathbf{0}\)), so \(eh\) and \(1_{A}\) agree at every element vacuously, and they are equal because \(\mathbf{1}\) separates mappings.
  • Contrast with \(\mathsf{ZFC}\): there, \(\emptyset\) has no elements by definition, and is unique by Extensionality. Here, the emptiness of \(\mathbf{0}\) is a theorem about mappings, derived from a property (initiality) that does not mention elements at all.

Coseparators

Exercise 14.4 (L–R 1.20) Use the fact that \(\mathbf{1}\) is a separator in the category of abstract sets to show that (in that category), if \(V\) can discriminate elements, then it can discriminate generalized elements. Thus, in \(\mathcal{S}\) the general \(T\) in Definition 14.7 could safely be replaced by \(T = \mathbf{1}\).

TipSolution

Assume \(V\) discriminates elements: for every set \(A\) and all \(b_0, b_1 \colon \mathbf{1}\to A\), \[ \bigl(\forall \varphi \colon A \to V,\ \varphi b_0 = \varphi b_1\bigr) \;\Longrightarrow\; b_0 = b_1 . \tag{*} \] Let \(a_0, a_1 \colon T \to A\) be generalized elements such that \(\varphi a_0 = \varphi a_1\) for every \(\varphi \colon A \to V\). We show \(a_0 = a_1\). Because \(\mathbf{1}\) separates mappings, it suffices to show \(a_0 t = a_1 t\) for every element \(t \colon \mathbf{1}\to T\).

Fix \(t \colon \mathbf{1}\to T\). Then \(a_0 t\) and \(a_1 t\) are elements of \(A\), and for every \(\varphi \colon A \to V\), by associativity, \[ \varphi (a_0 t) = (\varphi a_0) t = (\varphi a_1) t = \varphi (a_1 t). \] By \((*)\), \(a_0 t = a_1 t\). Since \(t\) was arbitrary, \(a_0 = a_1\).

The converse (discriminating generalized elements implies discriminating elements) is trivial, since elements are generalized elements with \(T = \mathbf{1}\). So in \(\mathcal{S}\) the two conditions are equivalent.

NoteRemarks
  • Before starting, write out exactly what must be shown: there are two layers of quantifiers (over \(t\) and over \(\varphi\)). Note that \((*)\) cannot be applied directly to \(a_0, a_1\), which are not elements.
  • Associativity does all the work: “evaluate first, then apply \(\varphi\)” equals “apply \(\varphi\), then evaluate”.
  • This is the dual of the role of the separator: \(\mathbf{1}\) lets us reduce statements about generalized elements to statements about ordinary elements. In categories where \(\mathbf{1}\) is not a separator (e.g. groups or vector spaces, see Exercise 14.6) the reduction fails, which is why Definition 14.7 is stated for general \(T\).

Uniqueness properties

Exercise 14.5 (L–R 1.28)  

  1. Show that identity arrows in a category are unique, i.e. if \(1_{A} \colon A \to A\) and \(1_{A}' \colon A \to A\) both satisfy the equations for identity arrows, then \(1_{A} = 1_{A}'\).
  2. Show that the set \(\mathbf{1}\) is unique “up to unique isomorphism”, i.e. if \(\mathbf{1}'\) also satisfies the axiom of the terminal set, then there are unique mappings \(f \colon \mathbf{1}\to \mathbf{1}'\) and \(g \colon \mathbf{1}' \to \mathbf{1}\), and that \(gf = 1_{\mathbf{1}}\) and \(fg = 1_{\mathbf{1}'}\).
  3. Similarly, show that the empty set \(\mathbf{0}\) is unique up to unique isomorphism.
TipSolution

(a) The identity equations say: \(h\,1_{A} = h\) for every \(h \colon A \to B\), and \(1_{A}\,k = k\) for every \(k \colon C \to A\); likewise for \(1_{A}'\). Consider the composite \(1_{A}\,1_{A}'\). Using that \(1_{A}'\) is a right identity, with \(h = 1_{A}\), we get \(1_{A}\,1_{A}' = 1_{A}\). Using that \(1_{A}\) is a left identity, with \(k = 1_{A}'\), we get \(1_{A}\,1_{A}' = 1_{A}'\). Hence \[ 1_{A} = 1_{A}\,1_{A}' = 1_{A}' . \]

(b) Since \(\mathbf{1}'\) satisfies the terminal set axiom, there is exactly one mapping \(f \colon \mathbf{1}\to \mathbf{1}'\); since \(\mathbf{1}\) does, there is exactly one mapping \(g \colon \mathbf{1}' \to \mathbf{1}\). Now \(gf \colon \mathbf{1}\to \mathbf{1}\), and the only mapping \(\mathbf{1}\to \mathbf{1}\) is \(1_{\mathbf{1}}\); so \(gf = 1_{\mathbf{1}}\). Symmetrically, \(fg \colon \mathbf{1}' \to \mathbf{1}'\) and the only such mapping is \(1_{\mathbf{1}'}\), so \(fg = 1_{\mathbf{1}'}\). Thus \(\mathbf{1}\cong \mathbf{1}'\). The isomorphism is unique: any isomorphism \(\mathbf{1}\to \mathbf{1}'\) is in particular a mapping \(\mathbf{1}\to \mathbf{1}'\), hence equals \(f\).

(c) Dually, let \(\mathbf{0}'\) also satisfy the initial set axiom. There is exactly one \(f \colon \mathbf{0}\to \mathbf{0}'\) (initiality of \(\mathbf{0}\)) and exactly one \(g \colon \mathbf{0}' \to \mathbf{0}\) (initiality of \(\mathbf{0}'\)). Then \(gf \colon \mathbf{0}\to \mathbf{0}\) must equal \(1_{\mathbf{0}}\), the only mapping \(\mathbf{0}\to \mathbf{0}\), and \(fg \colon \mathbf{0}' \to \mathbf{0}'\) must equal \(1_{\mathbf{0}'}\). So \(f\) is an isomorphism, and it is the only one, since it is the only mapping \(\mathbf{0}\to \mathbf{0}'\) at all.

NoteRemarks
  • The proofs use nothing specific to \(\mathcal{S}\): in any category, identities are unique and terminal (initial) objects are unique up to unique isomorphism. This is what justifies speaking of “the” terminal set: any statement about it is insensitive to which terminal set was chosen.
  • In (a), only “\(1_{A}'\) is a right identity” and “\(1_{A}\) is a left identity” are used, exactly as for identity elements of a monoid.
  • In (b), both composites must be checked; one-sided inverses do not make an isomorphism.
  • Compare with \(\mathsf{ZFC}\): \(\emptyset\) is literally unique by Extensionality, while \(\{\emptyset\}\), \(\{\{\emptyset\}\}\), and \(\{7\}\) are all different one-element sets. In the categorical approach these are indistinguishable: the theory only ever pins objects down up to (unique) isomorphism.

Categories of structures

Exercise 14.6 (L–R 1.30)  

  1. Show that (finite-dimensional) vector spaces as objects and linear transformations as arrows form a category with composition of arrows defined by composition of mappings. Show that a one-dimensional space \(S\) is a separator; is it a coseparator? Is the terminal object a separator?
  2. Show that groups as objects and group homomorphisms as arrows form a category with composition of arrows defined by composition of mappings. Show that the additive group of integers is a separator.
  3. Show that partially ordered sets as objects and monotone (= order-preserving) mappings as arrows form a category with composition of arrows defined by composition of mappings. Is the terminal object a separator in this category? Is there a coseparator?
  4. A finite state machine with two inputs \(\alpha\) and \(\beta\) is a finite set \(Q\) of “states” and a pair of endomaps \(\alpha, \beta \colon Q \to Q\) that effect the elementary state transitions of which the machine is capable. Given another such machine with state set \(Q'\), a homomorphism is a mapping \(\varphi \colon Q \to Q'\) of state sets preserving the transitions in the sense that \[ \varphi\alpha = \alpha'\varphi \qquad\text{and}\qquad \varphi\beta = \beta'\varphi , \] where \(\alpha', \beta' \colon Q' \to Q'\) denote the corresponding state transitions of the second machine. Define composition of homomorphisms and show that a category results.

In parts (a)–(c), “separator”, “coseparator” and “terminal object” are meant in the sense of Definition 14.6, Definition 14.7 and Definition 14.3, applied to the category at hand. In particular, the “elements” \(x \colon S \to X\) that a separator \(S\) uses to test arrows are arrows of that category (linear maps, homomorphisms, monotone maps), not arbitrary functions.

TipSolution: a remark common to (a)–(d)

In each case the arrows are certain mappings between underlying sets, composition is composition of mappings, and the identity arrow on an object is the identity mapping of its underlying set. Therefore, once we know that

  1. the identity mapping is an arrow, and
  2. the composite of two arrows is again an arrow,

the associativity and identity laws hold automatically, because they hold for mappings in \(\mathcal{S}\). So in each part the only real work in “show that a category results” is checking (i) and (ii). Strictly speaking an arrow should be recorded as the triple (domain, codomain, underlying mapping), since the same function can be an arrow between different structures on the same underlying sets; nothing below depends on this.

TipSolution to (a): vector spaces

Fix a field \(k\) and consider finite-dimensional vector spaces over \(k\) with linear maps.

Category. The identity map is linear. If \(f \colon U \to V\) and \(g \colon V \to W\) are linear then \(gf(\lambda u + \mu u') = g(\lambda f u + \mu f u') = \lambda\, gf u + \mu\, gf u'\), so \(gf\) is linear.

A one-dimensional space \(S\) is a separator. Fix a nonzero \(s \in S\), so \(S = \{\lambda s : \lambda \in k\}\). For every vector \(v\) in a space \(X\) the map \(x_v \colon S \to X\), \(x_v(\lambda s) = \lambda v\), is linear, and \(x_v(s) = v\). Now suppose \(f_1, f_2 \colon X \to Y\) satisfy \(f_1 x = f_2 x\) for all linear \(x \colon S \to X\). Then for every \(v \in X\), \[ f_1(v) = f_1 x_v (s) = f_2 x_v (s) = f_2(v), \] so \(f_1 = f_2\). (In fact linear maps \(S \to X\) correspond bijectively to vectors of \(X\) via \(x \mapsto x(s)\); this is the sense in which \(S\) plays the role of \(\mathbf{1}\).)

\(S\) is also a coseparator. Let \(a_0, a_1 \colon T \to A\) be linear with \(a_0 \neq a_1\). Then there is \(t \in T\) with \(w := a_0(t) - a_1(t) \neq 0\). Extend \(\{w\}\) to a basis \(\{w, e_2, \dots, e_n\}\) of \(A\) and let \(\varphi \colon A \to S\) be the linear map with \(\varphi(w) = s\) and \(\varphi(e_i) = 0\). Then \[ \varphi a_0 (t) - \varphi a_1 (t) = \varphi(w) = s \neq 0, \] so \(\varphi a_0 \neq \varphi a_1\). (We had to use generalized elements \(T \to A\) here, because maps out of the terminal object carry no information in this category; see the next point.)

The terminal object is not a separator. The zero space \(\{0\}\) is terminal: from any \(X\) there is exactly one linear map to it, the zero map. It is also initial: the only linear map \(\{0\} \to X\) sends \(0 \mapsto 0\). So for any \(f_1, f_2 \colon X \to Y\) and any \(x \colon \{0\} \to X\), both \(f_1 x\) and \(f_2 x\) are the unique map \(\{0\} \to Y\), hence equal. Taking \(f_1 = 1_{S}\) and \(f_2 = 0\) (distinct, since \(s \neq 0\)) shows that \(\{0\}\) does not separate.

TipSolution to (b): groups

Category. The identity map is a homomorphism. If \(f \colon G \to H\) and \(g \colon H \to K\) are homomorphisms then \(gf(xy) = g(f(x)f(y)) = gf(x)\, gf(y)\).

\((\mathbb{Z}, +)\) is a separator. For each element \(x\) of a group \(X\) the map \(h_x \colon \mathbb{Z}\to X\), \(h_x(n) = x^n\), is a homomorphism (since \(x^{m+n} = x^m x^n\)) with \(h_x(1) = x\). If \(f_1, f_2 \colon X \to Y\) satisfy \(f_1 h = f_2 h\) for every homomorphism \(h \colon \mathbb{Z}\to X\), then for every \(x \in X\), \[ f_1(x) = f_1 h_x(1) = f_2 h_x(1) = f_2(x), \] so \(f_1 = f_2\). (As in (a), homomorphisms \(\mathbb{Z}\to X\) correspond bijectively to elements of \(X\), because \(\mathbb{Z}\) is the free group on one generator.)

TipSolution to (c): partially ordered sets

Category. The identity is monotone. If \(f, g\) are monotone and \(x \le y\) then \(f(x) \le f(y)\), hence \(g f(x) \le g f(y)\).

The terminal object is a separator. The one-element poset \(\mathbf{1}= \{\ast\}\) is terminal (the constant map \(X \to \mathbf{1}\) is monotone and is the only map). Every function \(\mathbf{1}\to X\) is monotone, so monotone maps \(\mathbf{1}\to X\) correspond exactly to points of \(X\). If \(f_1 x = f_2 x\) for all \(x \colon \mathbf{1}\to X\), then \(f_1\) and \(f_2\) agree at every point, so they are equal as functions, hence as arrows. So, unlike (a) and (b), \(\mathbf{1}\) is a separator here.

There is a coseparator: the two-element chain \(\mathbf{2}= \{0 < 1\}\). Let \(a_0, a_1 \colon T \to A\) be monotone with \(a_0 \neq a_1\); pick \(t\) with \(p := a_0(t) \neq q := a_1(t)\). By antisymmetry, \(p \not\le q\) or \(q \not\le p\); say \(p \not\le q\) (otherwise swap the roles of \(p\) and \(q\)). Define \(\varphi \colon A \to \mathbf{2}\) by \[ \varphi(z) = \begin{cases} 1 & \text{if } p \le z,\\ 0 & \text{otherwise,} \end{cases} \] the indicator of the up-set \({\uparrow}p\). It is monotone: if \(z \le z'\) and \(\varphi(z) = 1\) then \(p \le z \le z'\), so \(\varphi(z') = 1\). And \(\varphi(p) = 1 \neq 0 = \varphi(q)\) since \(p \not\le q\). Hence \(\varphi a_0 (t) \neq \varphi a_1 (t)\), so \(\varphi a_0 \neq \varphi a_1\).

TipSolution to (d): finite state machines

Objects are triples \((Q, \alpha, \beta)\) with \(\alpha, \beta \colon Q \to Q\); an arrow \((Q, \alpha, \beta) \to (Q', \alpha', \beta')\) is a mapping \(\varphi \colon Q \to Q'\) with \(\varphi\alpha = \alpha'\varphi\) and \(\varphi\beta = \beta'\varphi\).

Composition is composition of the underlying mappings: given \(\varphi \colon (Q, \alpha, \beta) \to (Q', \alpha', \beta')\) and \(\psi \colon (Q', \alpha', \beta') \to (Q'', \alpha'', \beta'')\), set \(\psi \circ \varphi := \psi\varphi\). It is a homomorphism, by associativity in \(\mathcal{S}\): \[ (\psi\varphi)\alpha = \psi(\varphi\alpha) = \psi(\alpha'\varphi) = (\psi\alpha')\varphi = (\alpha''\psi)\varphi = \alpha''(\psi\varphi), \] and the same computation with \(\beta\) in place of \(\alpha\).

Identities: \(1_{Q}\) is a homomorphism \((Q, \alpha, \beta) \to (Q, \alpha, \beta)\), since \(1_{Q}\alpha = \alpha = \alpha\,1_{Q}\), and likewise for \(\beta\).

By the common remark above, associativity and the identity laws are inherited from \(\mathcal{S}\), so machines and their homomorphisms form a category.

NoteRemarks
  • Terminal = initial. In vector spaces (and in groups) the zero space (trivial group) is both terminal and initial. So in these categories \(\mathbf{0}\cong \mathbf{1}\): the Nondegeneracy axiom fails. This is a good way to see why Nondegeneracy is a genuine axiom and not a triviality.
  • Separators replace \(\mathbf{1}\). In (a) and (b) the terminal object sees nothing, and a different object (\(k\), respectively \(\mathbb{Z}\)) does the job of “detecting elements”. In each case that object is the free structure on one generator, so maps out of it are the same as elements of the underlying set.
  • Groups have no coseparator. If \(C\) were one, take a simple group \(G\) of cardinality larger than \(C\) (alternating groups \(A_n\), \(n \ge 5\), give arbitrarily large finite examples). The kernel of any homomorphism \(\varphi \colon G \to C\) is normal, hence trivial or all of \(G\); it cannot be trivial for cardinality reasons, so \(\varphi\) is trivial. Then no \(\varphi\) distinguishes two different elements of \(G\) (viewed as homomorphisms \(\mathbb{Z}\to G\)).
  • The order on the value object matters. The discrete two-element poset (no order relations between its two points) is not a coseparator in posets: monotone maps into it are constant on connected components, so for instance the two elements of the chain \(\mathbf{2}\) cannot be told apart by maps into it.
  • Finite dimension is only used in (a) for the easy extension of \(\{w\}\) to a basis; with the Axiom of Choice the same argument works for all vector spaces.
  • Machines preview a later theme of the book (Chapter 10): many categories of structures are categories of “sets with endomaps”. The terminal machine has one state with \(\alpha = \beta = \mathrm{id}\), so elements \(\mathbf{1}\to (Q, \alpha, \beta)\) are exactly the states fixed by both \(\alpha\) and \(\beta\). Hence \(\mathbf{1}\) is not a separator: for \(Q = \{0, 1\}\) with \(\alpha = \beta\) both equal to the swap there are no maps from \(\mathbf{1}\) at all, but \(1_{Q}\) and the swap are two distinct homomorphisms \(Q \to Q\).

TipQuestion

Posets satisfy every axiom of Chapter 1. What distinguishes them from abstract sets?

In posets a monotone bijection need not be an isomorphism: the identity function from the discrete two-element poset to the chain \(\mathbf{2}\) is monotone and bijective, but its inverse is not monotone. Such behaviour is ruled out by the further axioms of the book, which make the category of abstract sets a topos.
