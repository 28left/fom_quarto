Models of Set Theory

You may have noticed that, when introducing the axioms of \(\mathsf{ZFC}\), we never really answered the question “What is a set?” Instead, we developed a formal theory of axioms for a binary relation that somehow describe “how sets work”, that is, how we can obtain sets from given ones using well-known operations like power set and union.

We have then seen how we can develop a lot of standard mathematical objects (like \(\mathbb{N}\), \(\mathbb{R}\)) and techniques (like induction and definition by recursion) inside this formal system. In fact, most of mathematics can be developed formally inside this system. Almost all proofs you find in any standard math book are proofs that can be formalized in \(\mathsf{ZFC}\). It is very tedious to do this for us humans, but there is little doubt it can be done, and in fact, looking at the recent work on proof assistants (like Coq or Lean), many parts of mathematics have been formalized (albeit not directly in \(\mathsf{ZFC}\)).

This expressiveness gives \(\mathsf{ZFC}\) its foundational importance, but it is also the cause for much confusion for someone who first studies set theory.

From a pedagogical point of view, in what follows it is helpful to assume a “Platonist” perspective of mathematics, and set theory in particular, namely that sets and the relations between exist independently (and outside) of the \(\mathsf{ZFC}\) axioms. The set of real numbers exists, and our development of \(\mathbb{R}\) inside \(\mathsf{ZFC}\) is just a formal way to describe them. From this perspective, the axioms of \(\mathsf{ZF}\) (\(\mathsf{AC}\) is a little different) are just obvious truths about sets, just like the Peano axioms are obvious truths about natural numbers.

Among other things, this perspective allows us to treat \(\mathsf{ZF}\) just like any other mathematical theory, like group theory or the theory of algebraically closed fields. In particular, we can think about models of set theory the way we would think about models of group theory, in the sense of model theory.

A model would simply be a set \(M\) together with a binary relation \(E\) on \(S\) such that

\[ (M,E) \models \mathsf{ZF}, \]

that is, all axioms hold when interpreted in \((M,E)\). Note that we use “set” in this context not in the formal sense, but in the “meta”-sense (the Platonist world of sets).

Working in the meta-theory (“that what is mathematically true”), we know by Gödel’s completeness theorem that

  if \(\mathsf{ZF}\) is consistent, then it has a model.

This model should be seen as a set-theoretic universe: Its elements can be seen as sets, and the interpretation \(E\) of the \(\in\)-symbol will tell us how these sets are connected via the element-relation.

Note that \(E\) does not have to be the actual element relation on a set (of sets), but just some binary relation so that the axioms are satisfied.

In the meta-world, there are, of course, sets other than \(M\), but that does not matter here, since all we are interested in is giving some universe in which our axioms hold. (Timothy Chow has suggested that set theory should rather be called “universe theory. He is right in the sense that what axiomatic set theory does is to define such universes of sets, rather than what a set is.)

In the meta-theory, we can then follow the usual techniques to show provability or non-provability results.

If we want to prove that \(\mathsf{CH}\) is consistent with \(\mathsf{ZF}\) (assuming \(\mathsf{ZF}\) is consistent), we need to find a model in which both hold.

One difficulty in working with models of set theory is that they can look very different depending on whether you look at a model “from the inside” or “from the outside”.

To illustrate this, assume \(\mathsf{ZF}\) is consistent. Then, by the Löwenheim-Skolem theorem, there exists a countable model for \(\mathsf{ZF}\). Yet it is a theorem of \(\mathsf{ZF}\) that there exists an uncountable set. This is often referred to as Skolem’s paradox, although it is not really an antinomy.

If we break this down a bit, we see that the apparent paradox is really just a matter of perspective (inside or outside). Assume \((M,E)\) is a countable model of \(\mathsf{ZF}\). Then there exists \(x \in M\) such that there is no injection from \(x\) to the natural numbers. Since \(M\) is countable, \(x\) can have at most countably many elements. So why is this not a contradiction? We should really read the statement above as

  there is no injection in \(M\) from \(x\) to \(M\)’s version of the natural numbers.

In other words, even though \(x\) is countable from the outside, \(x\) appears uncountable inside \(M\) since a mapping witnessing its countability does not exist in \(M\).

This is a first warning sign that models of \(\mathsf{ZF}\) can behave in very unexpected ways. For another example, recall the axiom of Foundation asserts that the \(\in\)-relation is well-founded. But again, this means only “from the inside”.

Proposition 1
If \(\mathsf{ZF}\) is consistent, then there exists a model \((M,E)\) of \(\mathsf{ZF}\) such that \((M,E)\) is ill-founded.

NoteProof

Proof. Introduce new constant symbols \(c_n\) \((n \in \mathbb{N})\) and add the formulas \(\varphi_n \equiv c_{n+1} \in c_n\) to the axioms of \(\mathsf{ZF}\). It is not hard to show, using the compactness theorem, that \(\mathsf{ZF}+ \bigcup_n \varphi_n\) has a model \((M^*, E^*)\), for which the set \(\{c_n \colon n \in \mathbb{N}\}\) is ill-founded.

Since, as mentioned above, the model \((M^*,E^*)\) satisfies Foundation, the set \(\{c_n \colon n \in \mathbb{N}\}\) is actually not in the model (and neither can be any other set with an infinite descending \(\in\)-chain).

Mostowski collapse

If we restrict ourselves to models on which the \(E\)-relation is actually well-founded (i.e. from the outside), then interestingly these models look, in a way, “natural”: They can be assumed to be the \(\in\)-relation on a set. Such models are also called standard.

Given a set theoretic structure \((M,E)\) (not necessarily a model of \(\mathsf{ZF}\)), for each \(x \in M\) let \[\begin{equation*} \operatorname{ext}_E(x) = \{ y \in X \colon y\, E \, x \} \end{equation*}\]

If \(E\) behaves “set-like”, then it will respect the axiom of Extensionality, i.e. two sets are identical if and only if they have the same elements. Therefore we say that \(E\) is extensional if \[\begin{equation*} x,z \in X, \; x\neq z \quad \text{ implies } \quad \operatorname{ext}_E(x) \neq \operatorname{ext}_E(z). \end{equation*}\]

Furthermore, as stated above, we want to exclude infinite descending \(E\)-chains. Recall we say that \(E\) is well-founded if

every non-empty set \(Y \subseteq X\) has an \(E\)-minimal element.

Theorem 1 (Mostowski collapse)
If \(E\) is an extensional and well-founded relation on a set \(X\), then there exists a transitive set \(S\) and a bijection \(\pi: X \to S\) such that \[\begin{equation*} x \, E \, y \iff \pi(x) \in \pi(y) \quad \text{ for all $ x,y \in X$}. \end{equation*}\] Moreover, \(S\) and \({}\pi\) are unique.

NoteProof

Proof. We construct \({}\pi\) and \(S = \operatorname{im}(\pi)\) by recursion on \(E\), which is possible since it is well-founded.

For each \(x \in X\), let \[\begin{equation*} \pi(x) = \{\pi(y) \colon y \, E \, x \}, \end{equation*}\] and set \(S = \operatorname{ran}(\pi)\).

The injectivity of \({}\pi\) follows from the extensionality of \({}\pi\) by induction along \(E\):
Suppose we have shown \[\begin{equation*} \forall z \; (z E x \to \forall y \in X (\pi(z) = \pi(y) \to z = y)). \end{equation*}\] and we have to show that it holds for \(x\). Assume \(\pi(x) = \pi(y)\) for some \(y \in X\). Then \[\begin{align*} cEx &\Rightarrow& \pi(c) \in \pi(x) = \pi(y) &\\ &\Rightarrow& \pi(c) = \pi(z) & \qquad \text{ for some } zEy\\ &\Rightarrow& c=z & \qquad (\text{by ind. hyp., since } cEx)\\ &\Rightarrow& cEy &. \end{align*}\] Similarly, we get \(cEy \Rightarrow cEx\), hence \(x=y\) as desired due to the extensionality of \(E\). Finally we have \[\begin{align*} \pi(x) \in \pi(y) & \Rightarrow & \pi(x) = \pi(c) & \qquad \text{ for some } cEy \\ &\Rightarrow& x = c & \qquad \text{ (since ${}\pi$ is injective)}\\ &\Rightarrow& xEy & \end{align*}\] Thus \({}\pi\) is an isomorphism.

To see the uniqueness of \({}\pi\) and \(S\), assume \(\rho\), \(T\) are such that the statement of the theorem is satisfied. Then \(\pi \circ \rho^{-1}\) is an isomorphism between \((T, \in)\) and \((S,\in)\). Now apply the following lemma.

Lemma 1
Suppose \(X,Y\) are sets, and \({}\theta\) is an isomorphism between \((X,\in)\) and \((Y,\in)\). Then \(X=Y\) and \(\theta(x) = x\) for all \(x \in X\).

NoteProof

Proof. By induction on the well-founded relation \(\in\). Assume that \(\theta(z)=z\) for all \(z \in x\) and let \(y = \theta(x)\).

We have \(x \subseteq y\) because if \(z \in x\), then \(z = \theta(z) \in \theta(x) = y\).

We also have \(y \subseteq x\): Let \(t \in y\). Since \(y \in Y\), there is \(z \in X\) with \(\theta(z) = t\). Since \(\theta(z) \in y\) and \(y = \theta(x)\), we have \(z \in x\), and thus \(t = \theta(z) = z \in x\).

Hence \(x = y\), and this also implies \(\theta(x) = x\).

Corollary 1
If \(E\) is a well-order on a set \(X\), then \((X,E)\) is isomorphic to \((\alpha, \in)\) for a unique ordinal \(\alpha\).

NoteProof

Proof. Every linear order is extensional. Hence we can apply the Mostowski Collapse. It is easy to see that the resulting set is an ordinal.

Absoluteness and transitive models

Even if we consider well-founded standard models, interpreting set-theoretic statements in them can still lead to very different results, even for very simple formulas.

Example 1
Consider \(M = \{0, \{\{0\}\}\}\) and let \(\varphi \equiv \{\{0\}\} \subseteq 0\). Clearly \({}\varphi\) is not true from the “outside”. But what if we look at it from “inside” \(M\)? \(x \subseteq y\) means \(\forall z (z \in x \to z \in y)\). Inside \(M\) this means every set \(z\) in \(M\) that is an element of \(x\) is also an element of \(y\). But in \(M\), there is no element \(z \in \{\{0\}\}\), \(\{0\}\) is not an element of \(M\). Therefore, \[ (M, \in) \models \{\{0\}\} \subseteq 0. \]

In the example above, the set \(M\) is not transitive, which allowed it to “hide” its elements. It turns out that if we require our model to be transitive, the truth of simple formulas cannot vary between the “inside” and the “outside” perspective. We call such properties absolute.

Given a formula \({}\varphi\) and some class \(M\), we can relativize \({}\varphi\) with respect to \(M\) essentially by restricting all quantifiers in \({}\varphi\) to range over \(M\), i.e. \(\exists x\) becomes \(\exists x \in M\) and \(\forall x\) becomes \(\forall x \in M\). Note that classes are defined by formulas, so the resulting formula, which we denote by \(\varphi^M\), is still a formula of set theory.

Definition 1
We say a formula \(\varphi(x_0, \ldots, x_n)\) is absolute for a class \(M\) if for all \(a_0, \ldots, a_n \in M\) \[ \varphi^M(a_0, \ldots, a_n) \text{ holds} \iff \varphi(a_0, \ldots, a_n) \text{ holds}. \]

Exercise 1 If \(M\) is transitive, then for all \({}\varphi\), \[ (M, \in) \models \varphi \; \iff \; \varphi^M \text{ holds}. \]

Definition 2
A formula \({}\varphi\) is \(\Delta_0\) if it has no quantifiers or every quantifier of \({}\varphi\) is of the form \(\exists x \in y\) or \(\forall x \in y\) (i.e. every quantifier is bounded).

Lemma 2
If \(M\) is transitive and \({}\varphi\) is \(\Delta_0\), then \({}\varphi\) is absolute for \(M\).

NoteProof

Proof. Clearly \(x=y\) and \(x\in y\) are absolute for any \(M\). It is also not hard to see that if \({}\varphi\) and \({}\psi\) are absolute for \(M\), then so are \(\neg \varphi\) and \(\varphi \wedge \psi\). Hence all quantifier free formulas are absolute.

Finally, if \({}\varphi\) is absolute for \(M\), so is \(\psi \equiv \exists x \in y \: \varphi\): If \(\psi^M(y,\bar{z})\) holds for \(y,\bar{z} \in M\), then we have \([\exists x (x \in y \: \wedge \: \varphi(x,y,\bar{z}))]^M\), i.e., \(\exists x \in M(x \in y \: \wedge \: \varphi^M(x,y,\bar{z}))\). Since \(\varphi^M(x,y,\bar{z})\) if and only if \(\varphi(x,y,\bar{z})\), it follows that \(\exists x\in y \varphi(x,y,\bar{z})\), i.e. \({}\psi\).

Conversely, if for \(y,\bar{z} \in M\), \(\exists x\in y \varphi(x,y,\bar{z})\), then since \(M\) is transitive, \(x\) belongs to \(M\), and since \(\varphi(x,y,\bar{z})\) if and only \(\varphi^M(x,y,\bar{z})\), we have \(\exists x \in M \, (x \in y \: \wedge \: \varphi^M(x,y,\bar{z}) )\) and so \(\psi^M(y,\bar{z})\).

Proposition 2
Over \(\mathsf{ZF}\), the following properties can be expressed via \(\Delta_0\)-formulas and hence are absolute for any transitive class \(M\):

  • \(x = \emptyset\), \(x=y\), \(x \subseteq y\), \(z = x \cap y\), \(z = x \cup y\), \(x = \bigcap y\), \(x = \bigcup y\), \(z = \{x,y\}\), \(z =(x,y)\), \(z= x \times y\)
  • \(r\) is a relation, \(f\) is a function, \(x = \operatorname{dom}(f)\), \(y = \operatorname{ran}(f)\)
  • \(<\) is a linear order on \(x\), \(x\) is an ordinal, \(x\) is a limit ordinal, \(x=\omega\)

We leave the proof as an exercise.

We can extend the previous absoluteness result to a slightly larger family of formulas.

Definition 3
A formula \({}\varphi\) is

  • \(\Sigma_1\) if it is of the form \(\exists x_1 \dots \exists x_m \: \psi\) for a \(\Delta_0\)-formula \(\psi\),
  • \(\Pi_1\) if it is of the form \(\forall x_1 \dots \forall x_m \: \psi\) for a \(\Delta_0\)-formula \(\psi\).

Given a set of formulas \(T\) and formula \({}\varphi\), we say \({}\varphi\) is \(\Delta_1^{T}\) if there exists a \(\Sigma_1\)-formula \(\psi_\exists\) and a \(\Pi_1\)-formula \(\psi_\forall\) such that \[ T \vdash \varphi \leftrightarrow \psi_\exists \quad \text{ and } T \vdash \varphi \leftrightarrow \psi_\forall. \]

Proposition 3
If \(M\) is transitive and for all \(\sigma \in T\), \(\sigma^M\) holds, then any \(\Delta_1^T\)-formula is absolute for \(M\)

Levels of the von Neumann hierarchy as models

The absoluteness property of “simple” formulas can be put to use to identify many “almost” models of \(\mathsf{ZF}\) among the levels \(V_\alpha\) of the von Neumann hierarchy. Since each \(V_\alpha\) is transitive, we can check an axiom in \(V_\alpha\) by checking its relativization: all quantifiers range over \(V_\alpha\).

Recall that the rank of a set \(x\) is \[ \operatorname{rank}(x) = \min\{\alpha \colon x \in V_{\alpha+1}\}. \]

The hereditarily finite sets \(V_\omega\)

Lemma 3
Each \(V_\alpha\) is transitive.

NoteProof

Proof. By induction on \({}\alpha\). \(V_0 = \emptyset\) is trivially transitive. Suppose \(V_\alpha\) is transitive. We first note that \(V_\alpha \subseteq V_{\alpha+1}\): \[ z \in V_\alpha \; \overset{V_\alpha \text{ trans.}}{\Longrightarrow} \; z \subseteq V_\alpha \; \Longrightarrow \; z \in \mathcal{P}(V_\alpha) = V_{\alpha+1}. \] Now \[ x \in V_{\alpha+1} \; \Rightarrow \; x \in \mathcal{P}(V_\alpha) \; \Rightarrow \; x \subseteq V_\alpha \; \Rightarrow \; x \subseteq V_{\alpha+1}. \] Limit stages are fine, since a union of transitive sets is transitive.

Lemma 4
\(x \in V_\omega\) if and only if \(x \subseteq V_\omega\) and \(x\) is finite.

NoteProof

Proof. (\(\Rightarrow\)) Since \(V_\omega\) is transitive (Lemma 3), \(x \in V_\omega\) implies \(x \subseteq V_\omega\). Moreover, \(x \in V_n\) for some \(n < \omega\). By induction on \(n\), each \(V_n\) is finite (\(|V_{n+1}| = 2^{|V_n|}\)), and since \(V_n\) is transitive, \(x \subseteq V_n\), so \(x\) is finite.

(\(\Leftarrow\)) Let \(x \subseteq V_\omega\) be finite. If \(x = \emptyset\), then \(x \in V_1\). Otherwise, each \(y \in x\) has finite rank, so we can let \[ M = \max\{\operatorname{rank}(y) \colon y \in x\} < \omega. \] Then \(y \in V_{M+1}\) for all \(y \in x\), i.e. \(x \subseteq V_{M+1}\). Hence \(x \in V_{M+2} \subseteq V_\omega\).

Because of this lemma, the elements of \(V_\omega\) are also called the hereditarily finite sets.

Theorem 2
\((V_\omega, \in) \models \mathsf{ZF}- \mathsf{Infinity}\).

NoteProof

Proof. We go through the axioms one by one.

Extensionality: The axiom reads \[ \forall z \, (z \in x \leftrightarrow z \in y) \to x = y, \] but in \(V_\omega\) we have to read this as “\(\forall z \in V_\omega\)”. So let \(x,y \in V_\omega\). If \(z \in x \in V_\omega\), then by transitivity \(z \in V_\omega\). So if \(x\) and \(y\) have the same elements in \(V_\omega\), they have the same elements, and thus \(x = y\). In other words, Extensionality follows directly from transitivity.

(Without transitivity, Extensionality can fail: in \(M = \{\emptyset, \mathbb{R}\}\), the sets \(\emptyset \neq \mathbb{R}\) have the same elements in \(M\), namely none. The same happens for \(\{\emptyset, \mathbb{C}\}\).)

Foundation: Every non-empty set has an \(\in\)-minimal element. Let \(x \in V_\omega\), \(x \neq \emptyset\). Choose \(y \in x\) of minimal rank. If \(z \in y\), then \(\operatorname{rank}(z) < \operatorname{rank}(y)\), so \(z \notin x\). Hence \(y\) is \(\in\)-minimal in \(x\) (and \(y \in V_\omega\) by transitivity).

Comprehension: This follows from Lemma 4. Let \(a \in V_\omega\) and let \({}\varphi\) be a formula (possibly with parameters from \(V_\omega\)). Then \[ z = \{ v \in a \colon \varphi^{V_\omega}(v) \} \] (\(\varphi\) is evaluated in \(V_\omega\)) is a subset of \(a\). Since \(a \in V_n\) for some \(n < \omega\), by transitivity \(a \subseteq V_n\), so \(z \subseteq V_n\) and hence \(z \in \mathcal{P}(V_n) = V_{n+1} \subseteq V_\omega\).

Pairing: If \(x, y \in V_\omega\), then \(\{x,y\}\) is a finite subset of \(V_\omega\), hence in \(V_\omega\) by Lemma 4.

Union: Let \(a \in V_\omega\). Then \(\bigcup a\) is a finite union of finite sets and hence finite. Moreover, \[ \textstyle \bigcup a = \{z \in V_\omega \colon \exists y \in a \; (z \in y)\}, \] since \(a \in V_\omega\) implies, by transitivity, that every \(z \in \bigcup a\) is in \(V_\omega\), i.e. \(\bigcup a \subseteq V_\omega\). By Lemma 4, \(\bigcup a \in V_\omega\).

Power Set: If \(x \in V_\omega\), then \(x \in V_n\) for some \(n < \omega\), so \(x \subseteq V_n\) and \[ \mathcal{P}(x) \subseteq \mathcal{P}(V_n) = V_{n+1} \; \Rightarrow \; \mathcal{P}(x) \in \mathcal{P}(\mathcal{P}(V_n)) = V_{n+2} \subseteq V_\omega. \] (Alternatively, \(\mathcal{P}(x)\) is a finite subset of \(V_\omega\), so apply Lemma 4.)

Replacement: Suppose \({}\varphi\) defines (in \(V_\omega\)) a function \(f_\varphi: a \to V_\omega\), where \(a \in V_\omega\). Since \(a\) is finite, \(f_\varphi[a]\) is a finite subset of \(V_\omega\), hence, by Lemma 4, \(f_\varphi[a] \in V_\omega\).

On the other hand, Infinity fails in \(V_\omega\), since every element of \(V_\omega\) is finite, while any inductive set is infinite.

Beyond \(V_\omega\)

TipQuestion

Where are \(\mathbb{Q}\), \(\mathbb{R}\), \(\mathbb{C}\), … “located” in the von Neumann hierarchy?

Proposition 4
For every ordinal \({}\alpha\),

  • \(\operatorname{rank}(\alpha) = \alpha\),
  • \(\mathop{\mathrm{Ord}}\cap V_\alpha = \alpha\).

We can represent a rational number as a signed pair of mutually prime natural numbers \(\geq 1\), that is, as \[ \langle i, \langle m,n \rangle \rangle, \] where \(i\) codes the sign (with some fixed set representing \(0\)). Each such triple is in \(V_\omega\), by the Pairing argument above. Therefore, \[ \mathbb{Q}\subseteq V_\omega \quad \leadsto \quad \mathbb{Q}\in V_{\omega+1}. \]

The real numbers \(\mathbb{R}\) are the set of all Dedekind cuts. A Dedekind cut is a subset of \(\mathbb{Q}\), hence an element of \(\mathcal{P}(V_\omega) = V_{\omega+1}\). So all cuts are elements of \(V_{\omega+1}\), i.e. \(\mathbb{R}\subseteq V_{\omega+1}\), and therefore \[ \mathbb{R}\in V_{\omega+2}. \]

Finally, \(\mathbb{C}= \mathbb{R}\times \mathbb{R}\). An ordered pair \(\langle x,y \rangle = \{\{x\},\{x,y\}\}\) of elements of \(V_{\omega+1}\) is in \(V_{\omega+3}\), so \[ \mathbb{C}\in V_{\omega+4}. \]

Continuing like this, it seems that “elementary mathematics” lives in \(V_{\omega+\omega}\).

TipQuestion

Which axioms does \(V_{\omega+\omega}\) satisfy?

Replacement fails in \(V_{\omega+\omega}\): The function \(f: n \mapsto \omega + n\) is definable in \(V_{\omega+\omega}\) and has domain \(\omega \in V_{\omega+\omega}\). But its range \(\{\omega + n \colon n < \omega\}\) has rank \(\omega+\omega\) (by Proposition 4), so it is not an element of \(V_{\omega+\omega}\).

The other axioms, however, all hold, as the next theorem shows.

Limit levels

Let \(\mathsf{ZC}\) denote \(\mathsf{ZFC}- \mathsf{Replacement}\) (Zermelo set theory with Choice).

Theorem 3
If \(\alpha > \omega\) is a limit ordinal, then \((V_\alpha, \in) \models \mathsf{ZC}\), i.e. \((V_\alpha, \in) \models \mathsf{ZFC}- \mathsf{Replacement}\).

NoteProof

Proof. We verify a few axioms and leave the rest as an exercise.

Extensionality: The relativized version of this axiom is \[ \forall a,b \in V_\alpha \, ( \forall x\in V_\alpha (x \in a \leftrightarrow x \in b) \to a=b) \] This simply states that the \(\in\)-relation (as a binary relation) is extensional on \(V_\alpha\) (as defined above). It is easy to see that for every transitive set, the \(\in\)-relation is extensional.

Power Set: We have seen that \(\subseteq\) is absolute for transitive classes. Therefore, the relativized version of the Power Set axiom becomes \[ \forall a \in V_\alpha\, \exists y \in V_\alpha \forall z \in V_\alpha (z \in y \leftrightarrow z \subseteq a) \] This means we only need to have those subsets in the power set that are in \(V_\alpha\). In other words, we need to verify \[ \forall a \in V_\alpha\, ( \mathcal{P}(a) \cap V_\alpha \in V_\alpha) \] If \(a \in V_\alpha\), then \(a \in V_\beta\) for some \(\beta < \alpha\), since \({}\alpha\) is limit. Since \(V_\beta\) is transitive, \(a \subseteq V_\beta\) and thus \(\mathcal{P}(a)\subseteq \mathcal{P}(V_\beta) = V_{\beta+1}\), which in turn yields \(\mathcal{P}(a) \in V_{\beta+2}\)

If \(b \in \mathcal{P}(a) \cap V_\alpha\), then \(b \in V_{\beta+2}\). Therefore, \(\mathcal{P}(a) \cap V_\alpha \subseteq V_{\beta+2}\). It follows that \(\mathcal{P}(a) \cap V_\alpha \in V_{\beta+3} \subseteq V_\alpha\), as desired.

Infinity: We have seen that \(x = \omega\) is absolute for transitive classes. Hence \(V_\alpha\) will satisfy the Axiom of Infinity if \(\omega \in V_\alpha\). But this is true since we assume \(\alpha > \omega\).

How about \(V_{\omega_1}\)? Perhaps the failure of Replacement in \(V_{\omega+\omega}\) is due to \(\omega+\omega\) being “too small”. But Replacement fails in \(V_{\omega_1}\), too. Consider the formula \[ \varphi(x,y) \; \iff \; x \subseteq \omega\times\omega \; \wedge \; x \text{ is a well-order} \; \wedge \; y = \operatorname{type}(x). \] The set \[ A = \{ x \colon x \subseteq \omega\times\omega, \; x \text{ is a well-order} \} \] exists in \(V_{\omega_1}\) (it is a subset of \(\mathcal{P}(\omega\times\omega) \subseteq V_{\omega+1}\)). All the relevant notions are absolute for \(V_{\omega_1}\) (for example, the isomorphism between \(x\) and \(\operatorname{type}(x)\) is a subset of \(\omega \times \operatorname{type}(x)\) and hence in \(V_{\omega_1}\)), so \({}\varphi\) defines, in \(V_{\omega_1}\), a function \[ f: A \to V_{\omega_1}, \quad \operatorname{ran}(f) = \omega_1, \] since every countable ordinal is the order type of some well-order on a subset of \({}\omega\). But \(\operatorname{rank}(\omega_1) = \omega_1\), so \(\operatorname{ran}(f)\) does not exist in \(V_{\omega_1}\). Hence Replacement fails.

What is the problem with Replacement? The axiom says that if \({}\varphi\) defines a function, then the image of any set under this function is a set. Relativized to some \(M\), this means we need to find a set in \(M\) that contains the image. Here we run into a cardinality problem. The cardinality of \(V_\alpha\) can be much bigger than the cardinality of \({}\alpha\). For example, \(\mathcal{P}(\omega) \in V_{\omega+\omega}\) but \(\omega+\omega\) is countable. We could have a function that maps \(\mathcal{P}(\omega)\) to sets of rank cofinal in \(\omega+\omega\), which implies that the image cannot be in \(V_{\omega+\omega}\).

For \(V_\alpha\) to be a model, we would need \({}\alpha\) to be “unreachable” by such mappings. This gives rise to the notion of inaccessible cardinals, which we will introduce in the next section.
