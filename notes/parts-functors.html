Parts, Characteristic Functions, and Inverse Images

Functors, natural transformations, and representability

Author
Affiliation

Jan Reimann

Penn State — Math 558

Reading. Lawvere–Rosebrugh, Sets for Mathematics (L–R), §§2.3–2.5; Riehl, Category Theory in Context, §§1.2–1.4 and §2.1.

Goal. We first finish L–R’s treatment of parts by introducing the inverse image of a part along a map. We then restate everything we know about elements, parts, and characteristic functions in the language of modern category theory: hom-sets, functors, natural transformations, and representable functors. The punchline is a single sentence:

The axiom of §2.4 says that the functor \(\operatorname{Sub}\) is represented by the object \(2\), with universal element \(\mathrm{true}\).

Where we are

Throughout, \(\mathcal{S}\) denotes the category of abstract sets and mappings of L–R. So far we have the following axioms: \(\mathcal{S}\) is a category (L–R §1.4); it has a terminal object \(1\) (§1.2) and an initial object \(0\) (§1.5); it has binary sums (§2.1); \(1\) separates mappings (§1.5); and the axiom of §2.4, recalled below.

Elements and parts

Definition 1 An element of \(X\) is a map \(x\colon 1\to X\).

NoteAxiom: \(1\) separates mappings (L–R §1.5)

If \(f,g\colon X\to Y\) satisfy \(fx=gx\) for every element \(x\) of \(X\), then \(f=g\).

Definition 2 (L–R §§2.2–2.3, Def. 2.24)
Let \(X\) be a set.

  1. A part of \(X\) is a monomorphism \(i\colon A\rightarrowtail X\).

  2. For parts \(i\colon A\rightarrowtail X\) and \(j\colon B\rightarrowtail X\), we say \(i\) is included in \(j\), written \(i\subseteq_X j\), if there is a map \(k\colon A\to B\) with \(jk=i\). (Such a \(k\) is unique, since \(j\) is monic.)

  3. Parts \(i\) and \(j\) are equivalent, written \(i\equiv_X j\), if \(i\subseteq_X j\) and \(j\subseteq_X i\).

  4. An element \(x\) of \(X\) is a member of the part \(i\colon A\rightarrowtail X\), written \(x\in_X i\), if \(x=ia\) for some element \(a\) of \(A\). (Such an \(a\) is unique.)

We often drop the subscript \(X\).

Equivalent parts have the same members: if \(i=jk\) and \(x=ia\), then \(x=j(ka)\).

Lemma 1
Every element \(x\colon 1\to X\) is a part of \(X\).

NoteProof

Proof. If \(xa=xb\) for \(a,b\colon T\to 1\), then \(a=b\) because \(1\) is terminal. So \(x\) is monic.

ImportantConvention: elements, not generalized elements

L–R define membership for generalized elements \(x\colon T\to X\) with arbitrary domain \(T\), and their Definition 2.20 of characteristic function quantifies over all of these. For abstract sets it makes no difference whether we use all generalized elements or only elements \(1\to X\), by Proposition 1. In these notes we work with elements only.

Proposition 1 (Elements suffice; L–R pp. 36–37)
Let \(i\) and \(j\) be parts of \(X\). If every element of \(X\) that is a member of \(i\) is also a member of \(j\), then \(i\subseteq_X j\). Consequently, two parts with the same members are equivalent.

L–R justify this informally by the “arbitrariness of mappings” and promise a more explicit argument. One such argument uses the axiom of §2.4 together with the separator axiom; see Exercise 2.

Characteristic functions

Fix the set \(2\) with its element \(\mathrm{true}\colon 1\to 2\).

Definition 3 (L–R Def. 2.20)
A map \(\varphi\colon X\to 2\) is a characteristic function of a part \(i\) of \(X\) if for every element \(x\) of \(X\), \[ x\in i \iff \varphi x=\mathrm{true}. \]

NoteAxiom: Membership representation via truth values (L–R §2.4)
  1. Every map \(\varphi\colon X\to 2\) is the characteristic function of some part of \(X\).
  2. Every part \(i\) of \(X\) has exactly one characteristic function, denoted \(\chi_i\).

Exercise 3 shows that our definition of characteristic function agrees with L–R’s version for generalized elements.

Proposition 2 (L–R Prop. 2.22)
Parts \(i\) and \(j\) of \(X\) are equivalent if and only if \(\chi_i=\chi_j\).

NoteProof

Proof. If \(i\equiv j\), then \(i\) and \(j\) have the same members, so \(\chi_i\) is also a characteristic function of \(j\). By uniqueness, \(\chi_i=\chi_j\). Conversely, if \(\chi_i=\chi_j\), then for every element \(x\), \(x\in i \iff \chi_i x=\mathrm{true}\iff \chi_j x=\mathrm{true}\iff x\in j\). By Proposition 1, \(i\equiv j\).

Example 1 (L–R Ex. 2.21)
By Lemma 1, \(\mathrm{true}\colon 1\rightarrowtail 2\) is a part of \(2\). Its characteristic function is \(1_2\). Indeed, since the only map \(1\to 1\) is \(1_1\), an element \(y\) of \(2\) is a member of \(\mathrm{true}\) exactly when \(y=\mathrm{true}\), that is, when \(1_2\,y=\mathrm{true}\).

Remark 1. L–R point out right after the axiom that it is special to \(\mathcal{S}\) and to the so-called Boolean toposes. In a general topos there is still an object of truth values, usually written \(\Omega\) with an element \(\mathrm{true}\colon 1\to\Omega\), satisfying (1) and (2); but \(\Omega\) need not have just two elements. L–R §6.2 gives an example with three truth values.

Inverse image of a part

In naive set theory, the preimage of \(B\subseteq Y\) under \(f\colon X\to Y\) is \(\{x\in X : f(x)\in B\}\). The categorical version is defined by the same membership condition. This operation goes under many names: inverse image, preimage, substitution, pullback.

Definition 4 (L–R §2.5)
Let \(f\colon X\to Y\) and let \(j\) be a part of \(Y\). A part \(i\) of \(X\) is an inverse image of \(j\) along \(f\) if for every element \(x\) of \(X\), \[ x\in i \iff fx\in j . \]

Proposition 3
Any two inverse images of \(j\) along \(f\) are equivalent.

NoteProof

Proof. They have the same members, so this follows from Proposition 1.

We may therefore speak of the inverse image and write it \(f^{-1}(j)\), as L–R do (Ex. 2.39), keeping in mind that it is determined only up to equivalence.

L–R simply assert at the start of §2.5 that inverse images exist. In fact, existence is a consequence of the axiom of §2.4, and the proof yields L–R’s Theorem 2.33 at the same time.

Theorem 1 (Existence of inverse images; L–R Thm. 2.33)
Let \(f\colon X\to Y\) and let \(j\) be a part of \(Y\). The part of \(X\) whose characteristic function is \(\chi_j\circ f\) is an inverse image of \(j\) along \(f\). In particular, inverse images always exist, and \[ \chi_{f^{-1}(j)}=\chi_j\circ f . \]

NoteProof

Proof. By part (1) of the axiom, \(\chi_j\circ f\colon X\to 2\) is the characteristic function of some part \(i\) of \(X\). For every element \(x\) of \(X\), \[ x\in i \iff \chi_j(fx)=\mathrm{true}\iff fx\in j , \] using the definition of characteristic function first for \(i\), then for \(j\). So \(i\) is an inverse image of \(j\) along \(f\), and its characteristic function is \(\chi_j\circ f\).

Remark 2 (Comparison with ZFC). Part (1) of the axiom is a comprehension principle: for every “predicate” \(\varphi\colon X\to 2\) there is a part of \(X\) consisting of the elements where \(\varphi\) is true, \(\{x\in X: \varphi x=\mathrm{true}\}\). Compare the Comprehension (Separation) axiom of \(\mathsf{ZFC}\). There is an important difference: \(\mathsf{ZFC}\) separates by arbitrary formulas, while here we may separate only by predicates that are already given as maps \(X\to 2\). Richer forms of comprehension become available later, once we have exponentials and quantifiers.

Proposition 4 (L–R Prop. 2.31)
For any \(\psi\colon Y\to 2\), the map \(\psi\) is a characteristic function of \(\psi^{-1}(\mathrm{true})\). Consequently, \(\psi=\chi_j\) if and only if \(j\equiv\psi^{-1}(\mathrm{true})\).

NoteProof

Proof. By Example 1, \(y\in\mathrm{true}\) iff \(y=\mathrm{true}\). Hence \(x\in\psi^{-1}(\mathrm{true})\) iff \(\psi x\in\mathrm{true}\) iff \(\psi x=\mathrm{true}\), which proves the first claim. If \(j\equiv\psi^{-1}(\mathrm{true})\), then \(j\) has the same members as \(\psi^{-1}(\mathrm{true})\), so \(\psi\) is a characteristic function of \(j\). Conversely, if \(\psi=\chi_j\), then \(j\) and \(\psi^{-1}(\mathrm{true})\) have the same characteristic function, so they are equivalent by Proposition 2.

Proposition 5 (Functoriality of inverse image; L–R Ex. 2.30)
Let \(f\colon X\to Y\) and \(g\colon Y\to Z\), and let \(j,j'\) be parts of \(Y\) and \(k\) a part of \(Z\).

  1. \(1_Y^{-1}(j)\equiv j\).

  2. \((g\circ f)^{-1}(k)\equiv f^{-1}(g^{-1}(k))\).

  3. If \(j\subseteq j'\), then \(f^{-1}(j)\subseteq f^{-1}(j')\). In particular, if \(j\equiv j'\), then \(f^{-1}(j)\equiv f^{-1}(j')\).

NoteProof

Proof. Each statement is proved by comparing members and applying Proposition 1. (a) \(x\in1_Y^{-1}(j)\) iff \(x\in j\). (b) For an element \(x\) of \(X\), \[ x\in(gf)^{-1}(k) \iff g(fx)\in k \iff fx\in g^{-1}(k) \iff x\in f^{-1}(g^{-1}(k)) . \] (c) If \(j=j'k'\) and \(x\in f^{-1}(j)\), then \(fx\in j\), so \(fx\in j'\), so \(x\in f^{-1}(j')\).

Note the reversal of order in (b): pulling back along \(g\circ f\) is pulling back along \(g\) first, then along \(f\). L–R call this the contravariant functoriality of inverse image. The section on functors explains the terminology.

Remark 3. L–R prove Theorem 1 differently: by Proposition 4 and Proposition 5, \[ (\chi_j f)^{-1}(\mathrm{true})\equiv f^{-1}(\chi_j^{-1}(\mathrm{true}))\equiv f^{-1}(j), \] so \(\chi_j f\) is the characteristic function of \(f^{-1}(j)\). This argument only works once we know that \(f^{-1}(j)\) exists, which is why we proved existence first. The section on representability explains what lies behind L–R’s argument.

The next proposition anticipates the notion of pullback, which we study in L–R §3.5.

Proposition 6 (L–R Ex. 2.29)
Let \(j\colon B\rightarrowtail Y\) be a part of \(Y\), let \(f\colon X\to Y\), and let \(i\colon A\rightarrowtail X\) be \(f^{-1}(j)\).

  1. There is a unique \(f'\colon A\to B\) with \(jf'=fi\); that is, \(f\) restricted to \(i\) lands in \(j\).

  2. If \(m\) is any part of \(X\) such that \(fm=jg\) for some \(g\), then \(m\subseteq i\).

Thus \(f^{-1}(j)\) is the largest part of \(X\) on which \(f\) lands in \(j\).

Part (b) follows from Proposition 1: if \(x=mc\) is a member of \(m\), then \(fx=j(gc)\in j\), so \(x\in i\). Part (a) is Exercise 4.

Definition 5 (L–R Def. 2.36)
A part \(m\) of \(Y\) is an intersection of parts \(i\) and \(j\) of \(Y\), written \(m=i\cap j\), if for every element \(y\) of \(Y\), \(y\in m\) iff (\(y\in i\) and \(y\in j\)).

Proposition 7 (L–R Ex. 2.35, Rem. 2.37)
Let \(i\colon A\rightarrowtail Y\) and \(j\) be parts of \(Y\), and let \(k=i^{-1}(j)\). Then \(i\circ k\) is an intersection \(i\cap j\).

NoteProof

Proof. A composite of monos is monic, so \(ik\) is a part. If \(y=i(ka)\), then \(y\in i\), and \(y\in j\) because \(ka\in i^{-1}(j)\). Conversely, if \(y\in i\) and \(y\in j\), write \(y=ia\); then \(ia\in j\), so \(a\in i^{-1}(j)\), say \(a=kb\), and \(y=ikb\in ik\).

Hom-sets and the category of sets

Two kinds of sets

From now on we must keep two levels apart.

  • \(\mathcal{S}\) is the category of abstract sets that we are axiomatizing. Its objects are the things we study.
  • \(\mathsf{Set}\) is the category of sets of our metatheory (for instance, sets in the sense of \(\mathsf{ZFC}\)), with functions between them. These are the sets we use to talk about \(\mathcal{S}\).

In this section the collections we attach to an object of \(\mathcal{S}\) (its elements, its parts, its characteristic functions) are objects of \(\mathsf{Set}\), not of \(\mathcal{S}\).

Definition 6 (Hom-sets)
For objects \(X\), \(Y\) of a category \(\mathsf{C}\), write \(\mathsf{C}(X,Y)\) for the set of morphisms \(X\to Y\). (A common alternative notation is \(\operatorname{Hom}_\mathsf{C}(X,Y)\).)

Remark 4. Chapter 5 of L–R constructs, for sets \(X\) and \(Y\), an object \(Y^X\) of \(\mathcal{S}\) whose elements correspond to maps \(X\to Y\): an internal version of the external hom-set \(\mathcal{S}(X,Y)\). Do not confuse the two. In particular, we do not write \(Y^X\) for the hom-set.

Restating what we know

Definition 7
For a set \(X\), let \(\operatorname{Sub}(X)\) be the set of equivalence classes of parts of \(X\), partially ordered by inclusion.1 L–R say “part”; the standard term is subobject, hence the notation. We usually write \(j\) for the equivalence class of \(j\).

In this notation:

  • The elements of \(X\) form the hom-set \(\mathcal{S}(1,X)\).
  • The separator axiom says: if \(f,g\in\mathcal{S}(X,Y)\) agree on every \(x\in\mathcal{S}(1,X)\), then \(f=g\).
  • Proposition 1 says: the function \(\operatorname{Sub}(X)\to\mathcal{P}(\mathcal{S}(1,X))\) sending a part to its set of members is injective.
  • The axiom of §2.4 says the following.

Proposition 8
For every set \(X\), the assignment \(j\mapsto\chi_j\) is a well-defined bijection \[ \chi_X\colon \operatorname{Sub}(X)\longrightarrow\mathcal{S}(X,2). \]

NoteProof

Proof. Part (2) of the axiom gives the assignment on parts, and Proposition 2 (\(\Rightarrow\)) shows it is well defined on equivalence classes. It is injective by Proposition 2 (\(\Leftarrow\)) and surjective by part (1) of the axiom.

Functors

Moving things along a map

Given \(f\colon X\to Y\) in \(\mathcal{S}\), how do the collections attached to \(X\) relate to those attached to \(Y\)?

Collection How \(f\) moves it Direction
Elements \(x\mapsto f\circ x\), \(\;\mathcal{S}(1,X)\to\mathcal{S}(1,Y)\) forward
Characteristic functions \(\varphi\mapsto\varphi\circ f\), \(\;\mathcal{S}(Y,2)\to\mathcal{S}(X,2)\) backward
Parts \(j\mapsto f^{-1}(j)\), \(\;\operatorname{Sub}(Y)\to\operatorname{Sub}(X)\) backward

Maps out of a fixed object (elements) are pushed forward by composing after \(f\). Maps into a fixed object (characteristic functions) are pulled back by composing before \(f\).

In each case two laws hold. The identity map moves nothing: \[ 1_X\circ x=x,\qquad \varphi\circ 1_X=\varphi,\qquad 1_X^{-1}(j)\equiv j. \] Moving along a composite is moving in two steps, with the order preserved or reversed: \[ (g\circ f)\circ x=g\circ(f\circ x),\qquad \varphi\circ(g\circ f)=(\varphi\circ g)\circ f,\qquad (g\circ f)^{-1}(k)\equiv f^{-1}(g^{-1}(k)) . \] For elements and characteristic functions these are just the identity and associativity laws of a category; for parts, it is Proposition 5. A rule for moving things along maps that obeys these two laws is called a functor.

Functors and variance

Definition 8 (Riehl §1.3)
Let \(\mathsf{C}\) and \(\mathsf{D}\) be categories. A functor \(F\colon\mathsf{C}\to\mathsf{D}\) consists of

  • an object \(Fc\) of \(\mathsf{D}\) for each object \(c\) of \(\mathsf{C}\), and
  • a morphism \(Ff\colon Fc\to Fc'\) of \(\mathsf{D}\) for each morphism \(f\colon c\to c'\) of \(\mathsf{C}\),

such that \[ F(1_c)=1_{Fc}\qquad\text{and}\qquad F(g\circ f)=Fg\circ Ff \] for every object \(c\) and every composable pair \(f\), \(g\).

Example 2 \(\mathsf{Set}\) is a category, as is \(\mathsf{Pos}\), the category of partially ordered sets and order-preserving maps. Every category has an identity functor.

Some of the rules in the table reverse the direction of maps. These are handled by reversing the arrows of the domain category.

Definition 9 (Riehl §1.2)
The opposite category \(\mathsf{C}^\mathrm{op}\) has the same objects as \(\mathsf{C}\), and a morphism \(f^\mathrm{op}\colon c'\to c\) in \(\mathsf{C}^\mathrm{op}\) for each morphism \(f\colon c\to c'\) in \(\mathsf{C}\). Composition is defined by \(f^\mathrm{op}\circ g^\mathrm{op}=(g\circ f)^\mathrm{op}\), and identities are \(1_c^\mathrm{op}\).

Exercise 1 asks you to check that \(\mathsf{C}^\mathrm{op}\) is a category.

Definition 10 (Variance)
A contravariant functor from \(\mathsf{C}\) to \(\mathsf{D}\) is a functor \(F\colon\mathsf{C}^\mathrm{op}\to\mathsf{D}\). Unwinding the definitions, it sends each \(f\colon c\to c'\) to a morphism \(Ff\colon Fc'\to Fc\) in the opposite direction, with \[ F(1_c)=1_{Fc}\qquad\text{and}\qquad F(g\circ f)=Ff\circ Fg . \] A functor \(\mathsf{C}\to\mathsf{D}\) is called covariant when we want to stress the contrast. The variance of a functor says whether it preserves or reverses the direction of morphisms.

Proposition 9 (Hom-functors)
Let \(c\) be an object of a category \(\mathsf{C}\) whose hom-sets are sets.

  1. There is a functor \(\mathsf{C}(c,-)\colon\mathsf{C}\to\mathsf{Set}\) sending \(x\) to \(\mathsf{C}(c,x)\) and \(f\colon x\to y\) to \[ f_*\colon\mathsf{C}(c,x)\to\mathsf{C}(c,y),\qquad h\mapsto f\circ h . \]

  2. There is a functor \(\mathsf{C}(-,c)\colon\mathsf{C}^\mathrm{op}\to\mathsf{Set}\) sending \(x\) to \(\mathsf{C}(x,c)\) and \(f\colon x\to y\) to \[ f^*\colon\mathsf{C}(y,c)\to\mathsf{C}(x,c),\qquad h\mapsto h\circ f . \]

NoteProof

Proof.

  1. \((1_x)_*h=1_x\circ h=h\) and \((g\circ f)_*h=(g\circ f)\circ h=g\circ(f\circ h)=g_*f_*h\).
  2. \((1_x)^*h=h\) and \((g\circ f)^*h=h\circ(g\circ f)=(h\circ g)\circ f=f^*g^*h\).

So the functor laws for hom-functors are the identity and associativity axioms of a category. Two special cases are the first two rows of the table:

  • \(\mathcal{S}(1,-)\colon\mathcal{S}\to\mathsf{Set}\), the elements functor (covariant);
  • \(\mathcal{S}(-,2)\colon\mathcal{S}^\mathrm{op}\to\mathsf{Set}\), the characteristic functions functor (contravariant).

The third row is also a functor.

Theorem 2
There is a functor \(\operatorname{Sub}\colon\mathcal{S}^\mathrm{op}\to\mathsf{Set}\) sending \(X\) to \(\operatorname{Sub}(X)\) and \(f\colon X\to Y\) to \[ f^{-1}(-)\colon\operatorname{Sub}(Y)\to\operatorname{Sub}(X),\qquad j\mapsto f^{-1}(j). \]

NoteProof

Proof. The function \(f^{-1}(-)\) is well defined on equivalence classes by Proposition 5 (c). The functor laws are Proposition 5 (a) and (b).

Remark 5 (Why equivalence classes?). At the level of individual monos, inverse image is not a function: its defining membership condition determines \(f^{-1}(j)\) only up to equivalence. The functor laws also hold only up to equivalence: \((g\circ f)^{-1}(k)\) and \(f^{-1}(g^{-1}(k))\) are equivalent parts, not literally the same mono. Passing to equivalence classes makes \(f^{-1}(-)\) a genuine function and turns these equivalences into the equalities the definition of a functor requires.

Remark 6. By Proposition 5 (c), each \(f^{-1}(-)\) preserves inclusion, so \(\operatorname{Sub}\) is in fact a functor \(\mathcal{S}^\mathrm{op}\to\mathsf{Pos}\).

Remark 7 (Notation). Riehl writes \(f^*\) for precomposition with \(f\). Many authors also write \(f^*\) for inverse image along \(f\). Theorem 3 below shows that the two operations correspond under \(\chi\), so the clash is harmless. In these notes, inverse image is written \(f^{-1}(-)\).

Faithfulness and the separator axiom

Definition 11
A functor \(F\colon\mathsf{C}\to\mathsf{D}\) is faithful if for all objects \(c,c'\), the function \(\mathsf{C}(c,c')\to\mathsf{D}(Fc,Fc')\), \(f\mapsto Ff\), is injective.

Proposition 10
The axiom that \(1\) separates mappings holds if and only if the elements functor \(\mathcal{S}(1,-)\colon\mathcal{S}\to\mathsf{Set}\) is faithful.

NoteProof

Proof. For \(f,g\colon X\to Y\) we have \(f_*=g_*\) as functions \(\mathcal{S}(1,X)\to\mathcal{S}(1,Y)\) exactly when \(fx=gx\) for every element \(x\). Faithfulness says that this forces \(f=g\), which is the separator axiom.

A category whose terminal object separates mappings is called well-pointed. In the categories of variable sets we will meet later (L–R §6.2), \(\mathcal{S}(1,-)\) is still a functor but is no longer faithful: distinct maps can agree on all elements. This is why L–R use generalized elements \(T\to X\) in their definitions.

Remark 8 (Mixed variance). Letting both arguments vary gives a functor of two variables, \(\mathsf{C}(-,-)\colon\mathsf{C}^\mathrm{op}\times\mathsf{C}\to\mathsf{Set}\), contravariant in the first argument and covariant in the second. The exponential \(Y^X\) of L–R Chapter 5 behaves the same way.

Natural transformations

We now have two contravariant functors \(\operatorname{Sub}\) and \(\mathcal{S}(-,2)\), and for each \(X\) a bijection \(\chi_X\colon\operatorname{Sub}(X)\to\mathcal{S}(X,2)\) between their values. The question is whether this comparison respects the way both functors move along maps. Is “transport, then compare” the same as “compare, then transport”?

Definition 12 (Riehl §1.4)
Let \(F,G\colon\mathsf{C}\to\mathsf{D}\) be functors. A natural transformation \(\alpha\colon F\Rightarrow G\) consists of a morphism \(\alpha_c\colon Fc\to Gc\) in \(\mathsf{D}\) for each object \(c\) of \(\mathsf{C}\) (the components of \(\alpha\)), such that for every morphism \(f\colon c\to c'\) of \(\mathsf{C}\) the following square commutes: \[ \begin{CD} Fc @>{\alpha_c}>> Gc \\ @V{Ff}VV @VV{Gf}V \\ Fc' @>>{\alpha_{c'}}> Gc' \end{CD} \qquad\text{that is,}\qquad Gf\circ\alpha_c=\alpha_{c'}\circ Ff . \] A natural isomorphism is a natural transformation all of whose components are isomorphisms. We write \(F\cong G\).

For contravariant functors \(F,G\colon\mathsf{C}^\mathrm{op}\to\mathsf{Set}\) and a morphism \(f\colon x\to y\) of \(\mathsf{C}\), the naturality square reads \[ \begin{CD} Fy @>{\alpha_y}>> Gy \\ @V{Ff}VV @VV{Gf}V \\ Fx @>>{\alpha_x}> Gx \end{CD} \] Naturality only makes sense for two functors of the same variance; otherwise there is no square to check.

Example 3
Let \(u\colon Z\to Z'\) be a morphism of \(\mathsf{C}\). Postcomposition with \(u\) gives, for each \(x\), a function \(u_*\colon\mathsf{C}(x,Z)\to\mathsf{C}(x,Z')\). These form a natural transformation \(u_*\colon\mathsf{C}(-,Z)\Rightarrow\mathsf{C}(-,Z')\): for \(f\colon x\to y\) the square \[ \begin{CD} \mathsf{C}(y,Z) @>{u_*}>> \mathsf{C}(y,Z') \\ @V{f^*}VV @VV{f^*}V \\ \mathsf{C}(x,Z) @>>{u_*}> \mathsf{C}(x,Z') \end{CD} \] commutes because \(u\circ(h\circ f)=(u\circ h)\circ f\). Once again, naturality is associativity.

Now the main case.

Theorem 3
The bijections \(\chi_X\) form a natural isomorphism \[ \chi\colon\operatorname{Sub}\Longrightarrow\mathcal{S}(-,2). \]

NoteProof

Proof. Each component is a bijection by Proposition 8. Naturality means that for every \(f\colon X\to Y\) the square \[ \begin{CD} \operatorname{Sub}(Y) @>{\chi_Y}>> \mathcal{S}(Y,2) \\ @V{f^{-1}(-)}VV @VV{f^*}V \\ \operatorname{Sub}(X) @>>{\chi_X}> \mathcal{S}(X,2) \end{CD} \] commutes, that is, \(\chi_{f^{-1}(j)}=\chi_j\circ f\) for every part \(j\) of \(Y\). This is Theorem 1.

In words: parts of \(X\) are the same thing as maps \(X\to 2\), compatibly with every map \(f\). The axiom of §2.4 supplies the bijections, and L–R’s Theorem 2.33 says that they are compatible with inverse images.

Remark 9 (What “natural” means). Informally, a natural comparison is one that is defined uniformly in \(X\), without choosing anything specific to \(X\). Bijections that depend on choices, such as a chosen listing of the elements of \(X\), are typically not natural.

Representability and the universal element

Theorem 3 says that the functor \(\operatorname{Sub}\) is isomorphic to a hom-functor. This situation has a name.

Definition 13 (Riehl §2.1)
A functor \(F\colon\mathsf{C}^\mathrm{op}\to\mathsf{Set}\) is representable if there is an object \(c\) of \(\mathsf{C}\) and a natural isomorphism \(\mathsf{C}(-,c)\cong F\). We then say that \(c\) represents \(F\).

So \(\operatorname{Sub}\) is represented by \(2\). The next lemma shows that a natural transformation out of a hom-functor can be built from a single element.

Lemma 2
Let \(F\colon\mathsf{C}^\mathrm{op}\to\mathsf{Set}\) be a functor, \(c\) an object of \(\mathsf{C}\), and \(u\in Fc\). Then the functions \[ \theta_x\colon\mathsf{C}(x,c)\to Fx,\qquad \varphi\mapsto(F\varphi)(u), \] form a natural transformation \(\theta\colon\mathsf{C}(-,c)\Rightarrow F\).

NoteProof

Proof. For \(f\colon x'\to x\) and \(\varphi\colon x\to c\), functoriality of \(F\) gives \[ \theta_{x'}(f^*\varphi)=F(\varphi\circ f)(u)=(Ff\circ F\varphi)(u)=Ff\big(\theta_x(\varphi)\big), \] which is the naturality condition.

Definition 14
An element \(u\in Fc\) is a universal element of \(F\) if the natural transformation \(\theta\) of Lemma 2 is a natural isomorphism. Equivalently: for every object \(x\) and every \(a\in Fx\) there is exactly one \(\varphi\colon x\to c\) with \((F\varphi)(u)=a\).

Theorem 4
The part \(\mathrm{true}\colon 1\rightarrowtail 2\) is a universal element of \(\operatorname{Sub}\). Explicitly, for every set \(X\) and every part \(j\) of \(X\), there is exactly one \(\varphi\colon X\to 2\) with \(j\equiv\varphi^{-1}(\mathrm{true})\), and the resulting isomorphism \(\theta\) is the inverse of \(\chi\).

NoteProof

Proof. Here \(\theta_X(\varphi)=\varphi^{-1}(\mathrm{true})\). By Proposition 4, this is the part whose characteristic function is \(\varphi\), so \(\chi_X(\theta_X(\varphi))=\varphi\). Also by Proposition 4, \(\theta_X(\chi_X(j))=\chi_j^{-1}(\mathrm{true})\equiv j\). So \(\theta_X=\chi_X^{-1}\) is a bijection for every \(X\).

Note that the naturality of \(\theta\) came for free, from functoriality of \(\operatorname{Sub}\) alone (Lemma 2). The content of the axiom of §2.4 is that this particular \(\theta\), built from \(\mathrm{true}\), has bijective components. This is the idea behind L–R’s proof of Theorem 2.33.

Remark 10 (Preview: the Yoneda lemma). In the situation of Lemma 2, the identity \(1_c\in\mathsf{C}(c,c)\) is sent to \(\theta_c(1_c)=(F1_c)(u)=u\). The Yoneda lemma (Riehl §2.2) says that this is the general pattern: every natural transformation \(\alpha\colon\mathsf{C}(-,c)\Rightarrow F\) equals the \(\theta\) built from the element \(u=\alpha_c(1_c)\). In our case, \(\chi^{-1}\) is determined by \(\chi_2^{-1}(1_2)=\mathrm{true}\) (Example 1). So the entire correspondence between parts and characteristic functions is encoded in one piece of data: the part \(\mathrm{true}\) of \(2\).

Corollary 1
The truth-value object is unique up to unique isomorphism: if \(v\colon 1\rightarrowtail V\) is also a universal element of \(\operatorname{Sub}\), there is exactly one isomorphism \(\psi\colon 2\to V\) with \(\psi\circ\mathrm{true}=v\).

The proof is Exercise 8. It is a special case of a general fact: an object representing a functor is unique up to unique isomorphism.

Remark 11. In topos theory, the axiom “there is an object \(\Omega\) with a universal element \(\mathrm{true}\colon 1\rightarrowtail\Omega\) of \(\operatorname{Sub}\)” is called the existence of a subobject classifier. Its usual formulation uses pullbacks, which we introduce in L–R §3.5; Proposition 6 is a preview.
